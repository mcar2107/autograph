### Решения по вопросам планировщика

1. 2.4 и K4. Пользователь запретил трогать детектор, а спека (2.4) условна: «если detectRulingBend уводит трассу на листе с перспективой — передать perspective». Решение: исполнитель G3 сначала проверяет на синтетике «перспектива + волна», держит ли detectRulingBend без правки критерий 1/20 шага. Держит — detectRulingBend не трогается. Не держит — status: blocked, вопрос пользователю (правка детектора, пусть и добавочная, — его граница). Альтернатива «добавочное поле по K4 без спроса» отклонена: противоречит прямому условию пользователя.
2. K5, пиксели для магнитов. Решение: воркер отдаёт SheetImageData вместе с измерением transferable-буферами (без копии), главный поток держит их только пока открыт редактор, при закрытии отпускает. Альтернатива «магнит запросом в воркер» отклонена: сложнее (асинхронный отклик на отпускание), выигрыш в памяти лишь на время открытого редактора.
3. Длина plan.md 135 строк — принято.
